# stats.hedgehog-rp

Сайт для визуализации статистики сообщений беседы в VK проекта **«Ежиное RP»**.

Проект предназначен для сбора, агрегации и отображения статистики активности участников беседы. На сайте данные представлены в виде **топов, диаграмм и сводных показателей**.

## Сбор данных

Скрипты, отвечающие за сбор данных из VK, **не опубликованы** в репозитории по соображениям конфиденциальности. Ниже приведено их описание для понимания архитектуры проекта.

### Описание скриптов

1. **`fetch_messages.py`**  
   Выгружает сообщения и действия из беседы VK.  
   Данные сохраняются по годам в папки `messages` и `actions`

2. **`fetch_entities.py`**  
   Выгружает информацию о пользователях беседы и сохраняет её в файл `vk_entities.json`

3. **`stats_report.py`**  
   Обрабатывает все собранные данные и формирует итоговый файл `summary_stats.json`
