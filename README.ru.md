# Hedgehog RP Stats

</div>

**Статистика беседы** - аналитическая платформа для беседы сообщества Hedgehog RP во VK. Сервис объединяет инструменты сбора, обработки и визуализации данных о сообщениях, позволяя анализировать активность участников и отслеживать развитие сообщества за весь период его существования.

Рейтинги, диаграммы, графики и сводные показатели помогают определить наиболее активных участников и отслеживать динамику общения, рост сообщества и другие ключевые изменения.

## ✨ Возможности

- Просмотр статистики сообщений участников
- Рейтинги самых активных пользователей
- Визуализация данных с помощью диаграмм и графиков
- Анализ активности за разные периоды времени
- Сводные показатели по сообществу

## 🛠️ Технологии и инструменты

### Сайт

- **HTML, CSS, JavaScript** - базовые веб-технологии
- **Chart.js** - построение графиков и визуализация данных

### Обработка данных

- **Python** - обработка и агрегация данных
- **vk_api** - взаимодействие с API VK
- **pandas** - анализ и преобразование данных

### Инструменты разработки

- **ChatGPT** - большая часть сайта разработана с его помощью.

## 📦 Сбор данных

Скрипты сбора данных из VK не опубликованы в репозитории по соображениям конфиденциальности.

### Описание скриптов

1. **`fetch_messages.py`** - Выгружает сообщения и действия из беседы VK и сохраняет данные по годам.
2. **`fetch_entities.py`** - Собирает информацию об участниках беседы и сохраняет её в `vk_entities.json`.
3. **`stats_report.py`** - Обрабатывает собранные данные и формирует итоговый файл `summary_stats.json`.
