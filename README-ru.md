# Hedgehog RP Stats
> **Основной проект:** [hedgehog-rp](https://github.com/MaSStiK/hedgehog-rp)

**Статистика беседы** - аналитическая платформа для визуализации статистики сообщений сообщества VK проекта «Hedgehog RP». Сервис объединяет инструменты сбора, обработки и отображения данных, позволяя анализировать активность участников и развитие сообщества на протяжении всего периода его существования.

На сайте статистика представлена в виде рейтингов, диаграмм, графиков и сводных показателей, что позволяет быстро получать информацию о наиболее активных участниках, динамике общения и ключевых изменениях в жизни сообщества.

## ✨ Возможности
- Просмотр статистики сообщений участников
- Рейтинги самых активных пользователей
- Визуализация данных с помощью графиков и диаграмм
- Анализ активности за разные периоды времени
- Сводные показатели по сообществу

- **vk_api** - взаимодействие с API VK
- **pandas** - анализ и обработка данных

## 📦 Сбор данных
Скрипты, отвечающие за сбор данных из VK, не опубликованы в репозитории по соображениям конфиденциальности.

### ⚙️ Описание скриптов
1. **`fetch_messages.py`** - выгружает сообщения и действия из беседы VK и сохраняет данные по годам.
2. **`fetch_entities.py`** - собирает информацию об участниках беседы и сохраняет её в `vk_entities.json`.
3. **`stats_report.py`** - обрабатывает собранные данные и формирует итоговый файл `summary_stats.json`.
